# 正式 IMAP 只读盘点与模拟处理

本主题直接读取正式邮箱的 Inbox 与 Sent 文件夹，盘点 NAS 售后邮件，并保持系统现有的模拟发送行为。测试不接入 SMTP，不会向客户自动或真实发信。

## 目标

- 如实统计正式邮箱中读取到的邮件、确定收发配对、未配对和不支持关联的数量。
- 通过人工审核的历史候选归纳主要售后问题；统计口径与未分类/未审核数量一并保留。
- 对明确未回复的历史来信沿用既有工作流生成草稿或进入人工路径，但所有发送结果只写入模拟发件箱。

## 范围

- 数据源是正式邮箱中配置的 Inbox 和 Sent 文件夹；不再创建、复制或维护专用测试文件夹。
- IMAP 仅使用只读选择、UID 搜索和 BODY.PEEK[] 读取原文；不改动已读状态、标签、文件夹或原始邮件。
- 邮件原文、凭据和客户身份信息仅保存在隔离业务数据库，不写入本主题文档；报告只记录脱敏统计。
- 历史已回复邮件可在人工确认、补全事实并审核发布后进入知识库；本主题不再按邮件日期划分知识库来源和 Agent 对照集。

## 非目标

- 不构造可与人工回复隔离的 Agent 对照实验，不报告该类实验的检索质量、草稿对照准确率或端到端时延。
- 不接入 SMTP，不发送真实邮件，不以历史回放描述正式上线效果。
- 不新增运行时埋点、审核页面或生产发布。

## 验收标准

1. 正式邮箱接入只执行 IMAP 只读操作，真实网络发信次数为零。
2. 报告分别给出扫描邮件数、确定收发配对数、候选数、未配对/不支持原因，以及人工分类的主要售后主题和分类分母。
3. 所有业务数据写入新建的隔离数据库；不复用已有主题或开发数据库。
4. 模拟发送、人工审核和异常处理仍遵循 MVP 的既有安全边界。
