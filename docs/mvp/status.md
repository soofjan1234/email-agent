# MVP 状态

本文件是 MVP 设计与计划进度的唯一账本。文档名使用相对本目录的路径，不添加表内链接；详细验证证据保留在 `validation.md`。后续变更按主题在 `docs/changes/<主题>/status.md` 使用相同结构，跨月、跨年继续更新原文件。

设计状态：`待讨论`、`待确认`、`已确认`、`已替代`。
计划状态：`待实现`、`待验证`、`已完成`、`已放弃`。

设计已确认不代表功能已实现；计划只有实现与所需验证完成后才能记为已完成。已完成自动验证但仍缺必要外部验收时记为待验证。
